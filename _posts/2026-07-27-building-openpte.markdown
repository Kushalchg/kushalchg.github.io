To be honest The main reason I'm building Openpte is FOMO in the AI era. But
I just don't want to build slop that nobody uses(I already have many) so
lets build something useful for people, something that is already in market and
people are using, and also something people can put money on so started
building openpte.

Initially, I don't imagine it would go this far but everytime I think about
abandon this project one quote comes in my mind `If you are going to try, go all
the way otherwise don't even start` so i kept going.

--- 

I receltly launched
[openpte-beta](https://openpte.com) with the `reading`, `writing` and some of `speaking` question and user can practice but the project far from complete.
The project becomming more and more complex and feature-rich then I imagine
when I started building and I think this is the same for others (at least I like
to think like this). Since the beta launch, platform normally gets 3-4 signups in a day
and lots of people are practicing (almost every time there is atleast one
concurrent user) and for me that is a lot. Although I haven't completed all the
feature normal student uses while preparing for [PTE](https://www.pearsonpte.com/) but people are practicing and even one user purchased the premium (although he/she didn't practice that much). 

I don't know where this will go and where it ends but I just want to keep building and
complete features and mock test that normal users expect from this kind of
platform and write update (hopefully regular).

There are three main reasons to write openpte journey(hopefully regularly).

 - Journal the journey.
 - Improve SEO ( hopefully).
 - Improve my writing skill.
